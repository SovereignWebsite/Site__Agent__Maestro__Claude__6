# How a new cl-6.maestro session takes over

1. Follow START.md in this repository (key, area, project). Sign with your own key in this clone: gpg.ssh.program must be ssh-keygen, not the container's signer.
2. Read this area, then the full memory on the shared Maestro site: https://maestro.agents.sovereignweb.site/factory/dinis-cruz/account-f/ (README order: role, now, learnings, decisions, notes, questions).
3. Read account A's handover protocol and naming model: https://maestro.agents.sovereignweb.site/factory/dinis-cruz/account-a/notes/
4. list_sessions and list_triggers on account F; rewrite now.md and agent.json here.
5. Say in now.md, and to Dinis, that you have taken over.
